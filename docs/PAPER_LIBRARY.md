# Paper header & teacher library
The preview supports an expanded reading view, separate student-paper and teacher marking-scheme tabs, and **View saved version** to inspect persisted content. **Save paper & scheme** saves pending header/footer and question/guide changes. Complete setup becomes available only after saving and resolving the displayed validation checklist, including allocated marks matching the assessment total. Loaded question IDs no longer cause strict-validation save failures.

The optional **Good luck footer** has editable text, eight writing styles, colour, alignment, size, bold and italic controls. It is included in previews, saved headers, library templates and paper copies. Older saved headers receive a default footer. Leave its message blank to hide it.

Open an assessment to use **Paper header & layout**. Fields: school name, paper title, subject/module, class, date, duration, total marks, optional instructions, student name/number spaces, and optional school logo. Select a field to edit its text, alignment (left/centre/right), and bold setting. Logo alignment is independent. Blank fields are omitted. Preview the Student paper or Marking scheme; Print / Save PDF uses the browser print dialog with A4 print styles. Browser-generated print headers/footers and printer margins are controlled by the user. Headers lock after assessment setup is completed.

Choose **Save header** to persist the paper header. Unsaved header changes are protected by navigation prompts and must be saved before completing setup. Header revisions are separate from question revisions; every change records before/after values in the existing immutable assessment audit history.

Choose **Save to library** after saving your question/guide changes. Header templates contain only the header/formatting/logo reference. Saved papers contain assessment metadata, saved questions and marking scheme, plus the saved header. Student scripts, student answers, marks and uploaded source materials are never copied into a library snapshot. A header template can be selected inside another assessment's header editor and edited without changing the saved template. Choose **My library → Saved papers → Use a copy** to set the new paper title, subject/module, class and marks, then create a DRAFT with fresh question IDs and a copied header. Metadata changes update the matching printed fields. The saved master and original assessment remain unchanged; copied teaching materials can be uploaded independently if needed.

Libraries belong to individual teacher accounts. All library and header routes require existing sessions and same-origin write checks. Logo uploads accept PNG/JPEG up to 2 MB and four million pixels, decode and normalize to PNG (up to 800 × 800), strip embedded metadata, and remain private. Limits: 30 logos, 100 saved items per teacher. No hard-delete function is included in this increment.

API: GET/POST /api/library/logos; GET /api/library/logos/:id/original; GET/POST /api/library/items; GET /api/library/items/:id; POST /api/library/items/:id/copy with optional {assessment:{title,subject,className,totalMarks,kind}}; GET/PUT /api/assessments/:id/header with {header,revision}. Header shape is in packages/contracts/src/paper.ts. Migration 006 adds private logos, header revisions and snapshot tables.
